# ALLUR - Цифровой двойник завода

## Запуск сайта с ИИ

1. Установите Node.js 22 или новее.
2. Скопируйте `.env.example` в `.env` в этой папке.
3. Выберите сервис в `.env`:
   - **Gemini**: `AI_PROVIDER=gemini` и `GEMINI_API_KEY=ваш_ключ`
     - Ключ можно создать в Google AI Studio: https://aistudio.google.com/apikey
   - **Groq**: `AI_PROVIDER=groq` и `GROQ_API_KEY=ваш_ключ`
     - Ключ Groq: https://console.groq.com/keys
   - **OpenAI**: `AI_PROVIDER=openai` и `OPENAI_API_KEY=ваш_ключ`
   - Ключ хранится только на сервере; не добавляйте его в код браузера.
4. Откройте терминал в этой папке и выполните: `npm start`
   - Установка зависимостей не требуется. Также работает: `node server.mjs`
5. Откройте http://localhost:3000

В `.env.example` выбран Gemini, `GEMINI_MODEL=gemini-3.5-flash-lite`.
Можно указать другую доступную текстовую модель Gemini с generateContent.
Для OpenAI `OPENAI_MODEL` по умолчанию: `gpt-5-mini` (Responses API).
Без `AI_PROVIDER` сервер сохраняет совместимость с OpenAI.
После изменения `.env` перезапустите сервер.

API-запросы требуют интернет-подключения и доступа к выбранной модели.
Подписка ChatGPT сама по себе не предоставляет API-ключ.
Сервер слушает только локальный компьютер. Это локальный запуск;
для общего доступа потребуется отдельно настроить хостинг и доступ.

Без настройки API сайт работает: Обзор, Аналитика, 3D-цеха,
Тестовый режим и FAQ. ИИ честно показывает отсутствие подключения.
Для этих функций можно открыть `index.html` напрямую; для ИИ нужен сервер.

## Тестовый режим

Откройте вкладку слева, выберите день и примените изменения.
Все вкладки покажут сценарий. Переключатель «Использовать тестовые
данные» возвращает исходные данные и позволяет включить сценарий снова.
Сброс очищает сценарии обоих дней. Исходные записи не изменяются.

## ИИ помощник

Вкладка слева и кнопка «Спросить ИИ» внизу слева используют один диалог.
Помощнику передаются вопрос, последние сообщения и снимок текущих
показателей: период, нормативы, выпуск, качество, простои, оборудование
и применённый сценарий. Сервер отправляет запрос выбранному провайдеру:
Gemini generateContent, Groq Chat Completions или OpenAI Responses API.
История и сценарии хранятся в памяти страницы до её обновления.
Для OpenAI передаётся `store:false`. Условия обработки и хранения данных
у выбранного провайдера определяются вашим API-проектом.
Помощник отвечает на общие вопросы, но не выполняет интернет-поиск,
не управляет оборудованием и не изменяет данные сайта.

FAQ доступен без API, содержит 13 вопросов и поиск, поддерживает RU/ҚАЗ.
Светлая/чёрно-серая тема и выбранный язык сохраняются в браузере.

## Исходные данные

Архив за 01–02.10.2026, не живая телеметрия.
Сумма выпуска участков считает операции, не уникальные готовые машины.
Индекс риска простоя - эвристика, а не подтверждённая вероятность поломки.

## 3D-модели из открытых источников

Во вкладке 3D-цехов используются ABB IRB 2400 (ROS-Industrial),
седан Kenney Car Kit и промышленные модули 3D Assets.
Файлы, лицензии и сведения об изменениях находятся в `assets/`.
Источники можно открыть в самой вкладке. Это визуальные аналоги,
а не точная CAD-планировка Allur или конкретные модели выпускаемых машин.
GLB загружаются с локального сервера. Для прямого открытия `index.html`
предусмотрены встроенные копии моделей в `assets/models.js`.
Новая геометрия сохраняет вращение, масштабирование, полный экран,
анимацию шарниров, колёс и окрашивания. На узком экране камера
отдаляется, чтобы оборудование помещалось в рабочую область.

### Дополнительные модели из папки пользователя Allur_3d models

Подключены 11 GLB-файлов инструмента, стоек деталей, вентиляции,
подготовки краски и контроля качества во всех четырёх сценах.
Они также встроены в `assets/models.js` для запуска без сервера.
Сведения об источнике сохранены в `assets/MODEL-SOURCES.txt`.

## Быстрый ИИ и база знаний сайта

Бесплатная альтернатива: Groq Free Plan (квоты ограничены).
В `.env` укажите:
```
AI_PROVIDER=groq
GROQ_API_KEY=ваш_ключ
GROQ_MODEL=openai/gpt-oss-20b
```

Оставить Gemini:
```
AI_PROVIDER=gemini
GEMINI_MODEL=gemini-3.5-flash-lite
```

Сохраните свой `GEMINI_API_KEY`. После изменения `.env` перезапустите `npm start`.
Не подключайте платный тариф, если требуется только бесплатная квота.
Доступные модели и точные квоты проверяйте в своём кабинете провайдера.

## Работа помощника

Помощнику передаётся актуальный снимок всех известных данных сайта:
оба дня архива и простои, выбранные KPI и OEE по линиям, нормативы,
план по моделям, сценарии, телеметрия оборудования, FAQ с авторами,
процесс, функции разделов, управление и источники 3D-моделей.
Нормативы и ограничения вычислений также включены. Неизвестные данные
складов, VIN, выпуска по моделям и YTD не добавляются искусственно.
История запроса ограничена шестью последними сообщениями для скорости.
Точные вопросы из FAQ получают локальный ответ «Справка сайта», без API.
Произвольные вопросы анализирует выбранная модель. Это контекст, а не
обучение модели: точность выводов проверяйте по таблицам сайта.

## Оптимизация

- Лимит ответа 1400 токенов
- Сниженный уровень размышления для поддерживаемых моделей
- Один повтор при HTTP 500/502/503/504
- Общий предел ожидания API 35 секунд
- Остановка в чате отменяет запрос
- Ошибки 400 (запрос), 404 (модель), 401/403 (доступ), 429 (квота)
  показываются отдельно
- Сервер записывает код HTTP и провайдера в терминал
  без ключа, текста вопроса или данных завода

Бесплатные API не гарантируют время ответа и отсутствие сбоев.
